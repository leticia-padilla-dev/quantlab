# Claude Mobile Companion Reference

This folder is reserved for mobile companion prototype and visual reference files that complement the QuantLab Desktop operator workspace.

Purpose:
- companion UX reference
- navigation and information hierarchy
- shared tokens and surfaces alignment with Desktop

Not purpose:
- production-ready code
- execution logic
- broker or trading authority

Usage rules:
- use as visual/UX reference only
- do not copy prototype code wholesale into production
- keep Desktop as read-only operator workspace; mobile must not become an execution authority
