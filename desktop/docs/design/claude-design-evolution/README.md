# Claude Design Evolution Reference

This folder is reserved for the Claude Design prototype and visual reference files for QuantLab Desktop.

Purpose:
- visual direction
- UX hierarchy
- design tokens
- operator workspace reference
- incremental React Desktop convergence

Not purpose:
- production-ready code
- execution logic
- replacement for existing Desktop contracts
- source of broker or trading authority

Usage rules:
- use as visual/UX reference only
- do not copy prototype code wholesale into production
- implement changes through small slices
- start with tokens, then shell/status strip, then evidence rail, then compare refinements
- Desktop remains a read-only operator workspace and must not become a second execution authority

- tokens.css
- shell.css
- surfaces.css
- app.jsx
- shell.jsx
- surfaces.jsx
- tweaks-panel.jsx
- data.jsx
