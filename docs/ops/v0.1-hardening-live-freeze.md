# v0.1 Hardening — Live Execution Freeze

## Status

```yaml
live_execution: disabled
reason: v0.1_hardening_remediation
canonical_error: live_execution_disabled
reopening: human_review_required
```

QuantLab is currently available for research, paper execution, broker dry-run, validation, readiness checks, status inspection, fills, health, alerts, supervision and reconciliation.

Remote broker mutation is intentionally disabled while the `v0.1-hardening` program restores quantitative correctness, transaction integrity and local security boundaries.

## Frozen CLI routes

The following routes fail closed before standard command dispatch:

```text
--hyperliquid-submit-signed-action
--hyperliquid-submit-session
--hyperliquid-submit-sessions-cancel
--broker-order-validations-submit-real
```

A blocked request returns a `ConfigError` containing:

```text
live_execution_disabled
```

The process exits with a non-zero status through the existing CLI error mapping.

## Preserved capabilities

The freeze does not disable:

- research runs, sweeps and forward evaluation;
- paper execution and paper-session inspection;
- Kraken dry-run and validate-only behavior;
- local approval, bundle, submit-gate and submit-stub artifacts;
- Hyperliquid and Kraken readiness/preflight checks;
- broker status, fills, health, alerts, bounded supervision and reconciliation.

These surfaces must not mutate remote broker state.

## Reopening rule

Live execution must not be re-enabled by a feature toggle, environment variable or documentation-only decision.

A separate reopening review is required after:

1. all P0 correctness and broker-safety issues are closed;
2. executable security gates pass on the reviewed commit;
3. affected quantitative evidence is regenerated;
4. paper certification completes without unexplained accounting differences or ambiguous states;
5. independent broker-safety review is complete;
6. the operator records explicit approval for one bounded supervised path.

Passing these conditions may authorize one limited micro-live issue. It does not authorize automation, unattended execution or capital scaling.
